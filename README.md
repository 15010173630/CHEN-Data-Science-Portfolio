# CHEN Data Science Portfolio

## Purpose

This repository documents my coursework and projects for Introduction to Data Science. As an Economics student, I am using this portfolio to build practical skills in data analysis, visualization, and computational thinking. It will show my progress as I learn to use data to explore real-world questions and communicate clear insights.

## Tools and Skills

- Python
- pandas
- Data cleaning and exploratory data analysis
- Data visualization
- Google Colab and Jupyter notebooks
- Git, GitHub, and Markdown
## Planned Organization

As the portfolio grows, future work will be organized into dedicated folders:

- `EDA/` — exploratory data analysis and data-cleaning
- `Visualizations/` — charts, plots, and data storytelling
- `Models/` — introductory statistical models
- `Data/` — small datasets, source information, and data documentation
- `Notebooks/` — Jupyter or Google Colab notebooks


## Portfolio Status

This portfolio is a work in progress.
