# CHEN Data Science Portfolio


*Questions, small experiments, and projects from my Introduction to Data Science course.*


## Purpose


I am studying Economics, and this is where I keep the work I do while learning data science. I am using this portfolio to build practical skills in data analysis, visualization, and computational thinking. My first file was a simple check that Python and its libraries ran on my machine. After that I made a small Streamlit page and began working with a larger game sales dataset. Those steps are different in size, but they all belong here: this repository is meant to show how my thinking and my work change during the course.


I am especially interested in what a dataset can and cannot tell me. A filter or a chart can make a pattern easier to notice, but it does not answer every question by itself. I want future projects to include more of that reasoning: why I chose a question, what I tried, and where I still have doubts.

## Portfolio Status

The newest project, Bank Marketing ML Lab, is an extension of what we did in class building a decision tree. It runs as an application in Streamlit. You can upload your own CSV, or use the bank marketing dataset, pick your target, and adjust two hyperparameters. The results on the test set include accuracy, recall for each class, and a confusion matrix.

This project adds supervised learning and model deployment to my portfolio. The video game app used Python to filter data and create graphs and charts. The tidy data project was about preparing data for analysis. Here I have taken the decision tree steps from class through training and testing, then put them on Streamlit Community Cloud. The public app can be used without setting up Python on a local machine.
